Optional destination photos.
1. Drop a JPG here named after the destination "slug" (lowercase, spaces -> hyphens,
   anything that isn't a-z/0-9 removed), e.g.
     galle-fort.jpg
     sigiriya-the-ancient-rock-fortress.jpg
     gangaramaya-vihara-buddhist-temple.jpg
2. Add the slug (without .jpg) to manifest.json, e.g.  ["galle-fort", "kandy-lake"]
3. Run `npm run build` in the frontend folder.
Destinations without a photo show an illustrated scene for their type.
Use photos you have the right to use (your own, or Wikimedia Commons with attribution).
